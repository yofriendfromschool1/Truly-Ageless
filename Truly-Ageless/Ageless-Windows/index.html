The Law

What California demands
from every OS provider.

01
§ 1798.501(a)(1)

Collect user age at account setup

Every OS must present an "accessible interface" requiring users to disclose their birthdate or age before using their own device.

NOT PROVIDED
02
§ 1798.501(a)(2)

Expose a real-time age API to developers

OS providers must operate a "reasonably consistent real-time API" that broadcasts users' age brackets to any app developer who asks.

NOT PROVIDED
03
§ 1798.503(a)

Accept penalties for defiance

$2,500 per child per negligent violation. $7,500 per child per intentional violation. Enforced exclusively by the California Attorney General.

COME AND FIND US
04
§ 1798.501(a)(3)

"Minimize" the data you collected

After forcing you to collect age data, the law requires you to "minimize" it. Our solution: collect nothing. Zero is already minimal.

How it works

One script.
Zero compliance.

Ageless Windows overlays your existing OS identity with one that explicitly refuses to participate in age surveillance. Nothing is deleted. Everything is reversible.

01
Download the script
One PowerShell file. No dependencies, no package manager, no telemetry. Inspect every line before you run it.
Also available as become-ageless.sh for Debian/Ubuntu via our sister project, Ageless Linux.
02
Run as Administrator
Open an elevated PowerShell terminal and run .\become-ageless.ps1. Accept the legal disclaimer that tells you exactly what you're doing.
The script backs up your OEM registry values, writes the Ageless identity, and generates a one-click revert script.
03
You're now an OS provider
Your machine identifies as Ageless Windows. Compliance status: intentionally noncompliant. Welcome to civil disobedience.
Your PC works exactly the same. Nothing looks different. The only change is what your system declares about itself.
⚑
Optional: go flagrant
Run with -Flagrant to remove even the stub API. Installs a machine-readable REFUSAL and an invitation for the AG to enforce.
Intended for devices you plan to hand directly to children. Explicitly invites a test case.
Under the hood

The "age verification API"
we technically ship.

California law requires a "reasonably consistent real-time API" for age bracket signals. So we built one. It returns an error. Every time. By design.

age-verification-api.ps1
# "Reasonably consistent real-time API" # Cal. Civ. Code § 1798.501(a)(2) param([string]$Username) Write-Error "Age data not available." Write-Host "Ageless Windows does not collect" Write-Host "age information from users." Write-Host "All users are presumed to be" Write-Host "of indeterminate age." Write-Host "" Write-Host "Have a nice day." exit 1

Technically, AB 1043 allows the California Attorney General to pursue civil penalties against noncompliant OS providers. In practice, enforcement against individual users converting their own machines is extraordinarily unlikely. The -Flagrant mode exists specifically to invite a test case.
